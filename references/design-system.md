# 视觉规范与图形语法

本文件是 NoteGlyph 的视觉基线。换书时只换内容，不换这套符号的含义。

## 1. 色彩 tokens

| 变量 | 日间 | 用法 |
|---|---|---|
| `--bg` | `#edf1ec` | 页面浅灰绿底 |
| `--card` | `#fbfcfa` | 卡片近白 |
| `--ink` | `#1b332a` | 标题、深色“你”圆 |
| `--ink-soft` | `#476052` | 正文解释 |
| `--green` | `#286449` | 主绿：结论、强调、独有能力形状 |
| `--green-2` | `#4c8b66` | 绿色路径与箭头线 |
| `--wash` | `#e8f3e9` | 根本前提的浅绿底 |
| `--gray-shape` | `#a6b0aa` | 可替代、重复的单位 |
| `--gray-text` | `#7d8a81` | 辅助说明 |
| `--gray-line` | `#c8d1cb` | 分隔线、门槛 |
| `--border` | `#d6dfd7` | 细边框 |

深色模式已在 `assets/gallery-template.html` 的 `@media (prefers-color-scheme: dark)` 中设好。SVG 一律用语义类上色，不写死颜色，这样才能随系统切换，单卡导出的 PNG 也会跟着当前主题走。

## 2. 核心层：适用于任何材料

这些符号只描述**结构**，不带价值判断，书、论文、长文都可以用。

| 概念 | 画法 | 不要这样用 |
|---|---|---|
| 左右对比 | 灰色**竖**虚线（`grey-stroke dash`） | 换成粗实线或绿色线 |
| 门槛 / 过滤条件 | 灰色**横**虚线 | 当成时间轴刻度或目标线 |
| 流程、因果 | 细实线 + 小三角箭头（`polygon`） | 每两个节点都连线，画成思维导图 |
| 根本前提、必须先做的一步 | 浅绿底框（`wash-fill`） | 每一步都高亮 |
| 读者 | 墨色圆（`you`），圆心写“你”/“you”（`you-tx`） | 换成头像、emoji 或别人的名字 |
| 摸索、多次试错 | 绿色弯折虚线 + 离散小绿点 | 画成一路笔直的胜利箭头 |
| 投入力度 | 线条粗细有含义 | 为了好看随意加粗 |

## 3. 价值层：只在原文作出价值判断时使用

| 概念 | 画法 | 前提 |
|---|---|---|
| 被批量塑造、可替代、行不通的路径 | 重复、同尺寸的灰色圆点/方块/胶囊（`grey-shape`） | 原文确实否定或贬低了这条路 |
| 有效、可积累的路径 | 绿色线、节点或框 | 原文确实肯定了这条路 |
| **独有能力** | 唯一的固定不规则形：`<use href="#ng-unique" …/>` | 原文讨论的正是“别人难以复制的个人能力” |

作者没有在比较“好与坏”时，不要硬造灰绿二分：用中性的描边节点和核心层符号表达，必要时在摘要里写清适用条件。**论文笔记默认只用核心层。**

## 4. 固定不规则形

形状定义在模板里（`id="ng-unique"`），以原点为中心，约 62×59。卡片里只能这样引用，可以平移和缩放，不能改轮廓：

```svg
<use href="#ng-unique" transform="translate(481 74) scale(0.9)" class="green-fill"/>
<text x="481" y="78" text-anchor="middle" class="you-tx">独有</text>
```

渲染器只接受 `href="#ng-unique"`，其他引用一律拒绝。卡片不涉及独有能力时，不需要出现这个形状，即使结论是积极的。

## 5. 画图

画布固定 `viewBox="0 0 560 228"`，只写子元素，不写外层 `<svg>`。

- 文字类：`tx` 一般标签；`sm` 辅助/灰注释；`mid` 重点中性文字；`strong` 绿色强调；`tiny` 极小说明；`you-tx` 深色底上的浅色字。
- 图形类：`grey-shape`、`grey-stroke`、`grey-stroke-strong`、`green-fill`、`green-stroke`、`wash-fill`、`you`；`dash` 加虚线。
- 允许的元素：`g` `line` `path` `circle` `rect` `text` `ellipse` `polyline` `polygon` `use`（仅 `#ng-unique`）。没有 `marker`，箭头用小三角 `polygon` 画。
- 渲染器拒绝 `script`、`foreignObject`、`image`、事件属性、外部链接和未定义的类。文字里的 `&`、`<` 要转义。
- 留出边距：文字离画布边缘至少 12，节点之间不要贴着；英文标签比中文长，先估宽度再定框。

### 范式 A：左右对比
x≈280 一条灰色竖虚线；左右各一个小标题；至少一条元素或箭头说明两侧的关系，不要画成两张无关的小图。（示例：论语 #01、Meditations #02）

### 范式 B：路径与积累
只画“线性、复利、逐步积累”这类思维机制；不是数据就**不画刻度和数值**，并加一句注释说明这是示意。

### 范式 C：方向与靶心
灰色粗箭头＝费力但偏离方向，绿色细箭头＝朝向目标；靶心用普通同心圆，不用独有能力形状。（示例：论语 #06）

### 范式 D：流程与前提
2–4 步，从左到右或从上到下；浅绿底只给**根本前提**。类比关系可以画成上下两行对照。（示例：论语 #07）

### 范式 E：门槛与反馈
横灰虚线标门槛，绿色虚线标小步试探与反馈。只在原文确实讲门槛或反馈时使用。（示例：论语 #05、Meditations #04）

### 范式 F：因果链
左→右的节点链，把作者指出的**杠杆点**用绿色描边框标出，“你”从下方指向它。（示例：Meditations #01）

## 6. 卡片信息层级

1. **顶行**：`#01`（等宽）+ 书名（中文加《》，英文用斜体）+ 主题标签。
2. **标题**：两行结论。中文通常“前半句，/ 后半句”；英文每行一个完整意群。
3. **机制图**：高约 229px，上下极细分隔线。
4. **证据**：引用类型标签 + 正文 + 可选原语言节选 + 出处与“核对原文”链接、“存图”按钮。

卡片无阴影、圆角约 17px、内边距约 25/27px，两列间距 20px，页面宽约 1188px。只用系统字体栈，不内嵌字体文件。

## 7. 页面与交互

- 封面：书名、副题、一句说明、卡片数与主题数。
- 图例：自动只显示本卡组用到的符号。
- 主题筛选由 `topics` 动态生成；视觉卡片 ↔ 文字提要可切换，提要标出“已制卡 / 待制卡”。
- 单卡存图：把当前卡片按当前主题导出为 2x PNG（离线，无依赖），失败时退回 SVG。
- 窄屏单列、无横向滚动；`@media print` 避免卡片跨页。

## 8. 验收红线

- 没有出处，或把意译、编辑提炼当成原话。
- 标题只是主题名；图里只有一个概念图标，没有机制。
- 价值层符号出现在原文没有价值判断的地方；独有能力形状被用于别的概念或被改了轮廓。
- 多张卡套用同一张图只换文字。
- 图与原文矛盾（作者讲“有条件”，图里画成“必然”）。
- 手机上文字溢出、压线；深色模式下对比度不够。
- 交付的是死图，而不是能继续扩充的卡组。
